# Important contacts

Copy this file to `contacts.md` (gitignored), or run `/contacts suggest` to seed it from your Sent mail.
The skills use these tiers to prioritize mail. Senders not listed get no boost.

| Tier | Meaning | Expected response |
|---|---|---|
| 1 VIP | Always surface; never file unanswered | Same day |
| 2 Important | Prioritize over unknown senders | Within a few days |
| 3 Known | Recognized and routine; no boost | Whenever |

Entries go in each tier's table, one row per contact: `| address-or-@domain | name | note |`. A `@domain` entry matches any sender at that domain. A specific address takes precedence over a domain entry.
